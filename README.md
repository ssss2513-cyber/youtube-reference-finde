# 유튜브 레퍼런스 파인더

주제를 입력하면 유튜브에서 영상 제작/편집 레퍼런스가 될 만한 영상을 검색해서
카드 형태로 보여주고, 직접 만든 썸네일의 "후킹 강도"도 진단해주는 로컬 웹앱입니다.
설치가 필요 없고, `index.html`을 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다.

## 사용법

1. `index.html`을 더블클릭해서 브라우저로 엽니다.
2. 처음 실행하면 API 키 설정 창이 뜹니다. 아래 안내대로 무료 키를 발급받아 입력하세요.
3. 검색어(주제)를 입력하고 정렬/영상 길이/업로드 기간을 필터링해서 검색합니다.
4. 마음에 드는 영상은 "☆ 저장" 버튼으로 보관함에 저장할 수 있습니다.
5. "저장한 레퍼런스" 탭에서 모아보고, "마크다운으로 복사" 버튼으로 목록을
   기획서 등에 붙여넣을 수 있는 형태로 클립보드에 복사할 수 있습니다.

검색 결과 상단에는 제목의 반전·갈등·감정·호기심·구체성을 규칙 기반으로 분석한
**후킹 카피 추천**이 표시됩니다. 카피로 응용하기 좋은 영상 최대 3개와 후킹 점수,
검색 주제에 맞춘 짧은 추천 문구 3개, 선정 이유를 함께 확인할 수 있습니다.
조회수는 실제 반응을 보여주는 참고값으로만 사용하며 후킹 점수에는 합산하지 않습니다.
추천 목록에는 후킹 점수 80점 이상인 영상만 포함되며, 검색할 때마다 후보 영상의 순서와
추천 카피 조합을 새로 섞어서 보여줍니다.
80점 이상 영상이 없으면 조회수, 구독자 대비 조회수, 업로드 후 일평균 조회수와
`영상 길이 × 조회수`로 계산한 시청 잠재량을 조합해 대체 추천합니다. 실제 시청시간은
YouTube 공개 API에서 제공하지 않으므로 시청 잠재량은 비교용 추정 지표입니다.

## YouTube Data API 키 발급받기 (무료)

1. [Google Cloud Console](https://console.cloud.google.com/) 접속 후 로그인
2. 새 프로젝트 생성 (또는 기존 프로젝트 선택)
3. [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) 페이지에서 "사용 설정" 클릭
4. 좌측 메뉴 "API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키" 클릭
5. 발급된 키를 복사해서 앱의 "⚙ API 키 설정"에 붙여넣기

무료 할당량은 하루 10,000 유닛이며, 검색 1회에 약 100~130 유닛 정도 소모됩니다
(하루 약 70~90회 검색 가능). 키는 이 브라우저의 localStorage에만 저장되고
외부로 전송되지 않습니다.

## 참고

- API 키를 다른 사람과 공유하거나 공개 저장소에 올리지 마세요.
- 검색 결과가 400/403 오류를 낸다면 API 키가 올바른지, YouTube Data API v3가
  사용 설정되어 있는지 확인하세요.

## 썸네일 진단 → ChatGPT로 실제 수정까지

1. "썸네일 진단" 탭에서 이미지 업로드 → "진단하기" 클릭
2. 상단에 "🔧 이 순서대로 고쳐보세요" 카드에서 영향이 큰 순서대로 문제점 확인
3. 그 카드 맨 아래 **"🤖 ChatGPT용 수정 프롬프트 복사"** 버튼 클릭 → 진단 결과 기반 수정 지시문이 클립보드에 복사됨
4. [chatgpt.com](https://chatgpt.com) 접속 → 새 대화 시작 → 원본 썸네일 이미지 첨부 + 복사한 프롬프트 붙여넣기 → 전송
5. ChatGPT가 만들어주는 수정본 이미지를 다운로드해서 사용

⚠️ 참고: Claude(claude.ai)는 이미지를 보고 설명할 수는 있지만 이미지를 생성·편집해서
돌려주는 기능은 없습니다. 실제 이미지 수정은 이미지 생성 기능이 있는 ChatGPT(또는
유사한 이미지 생성 AI)를 사용해야 합니다. 이 앱의 프롬프트 복사 버튼은 ChatGPT에 붙여넣는
용도로 만들어졌습니다.

## 오늘 사용량(쿼터) 표시

화면 우측 상단에 "오늘 사용량: X / 10,000 유닛" 게이지가 표시됩니다.
YouTube Data API는 결제가 아니라 하루 무료 할당량 방식이라 실제 돈이 청구되지
않습니다 — 이 게이지는 오늘 한도에 얼마나 가까워졌는지 보여주는 지표이며,
메인 검색 1회당 약 102 유닛이 소모됩니다(영상·채널 통계 조회 포함, 하루 약 90회). 100%에 가까워지면
막대가 주황색 → 빨간색으로 바뀝니다. 매일 자정(기기 시간 기준)에 자동으로
초기화됩니다. 이 수치는 이 브라우저에서 이 앱으로 실행한 요청만 집계하므로,
Google Cloud Console의 실제 사용량과 약간 차이가 날 수 있습니다.
