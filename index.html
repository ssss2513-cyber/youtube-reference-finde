🔑 YouTube 검색 키 발급받기

검색을 하려면 무료 인증키가 하나 필요해요. 구글 계정만 있으면 5분이면 끝나요. 아래 순서대로 버튼을 눌러가며 따라오시면 됩니다. 키는 이 컴퓨터의 이 브라우저에만 저장되고 다른 곳으로 전송되지 않아요.

1
구글 계정으로 로그인
평소 쓰시는 Gmail(구글) 계정이 있으면 됩니다. 없으면 새로 만드셔야 해요.
2
프로젝트 만들기
아래 버튼을 누르면 새 탭이 열려요. 화면 위쪽 "프로젝트 만들기"(또는 "New Project")를 누르고, 이름은 아무거나 입력한 뒤 파란색 "만들기(Create)" 버튼을 누르세요.
➜ 프로젝트 만들기 페이지 열기
3
YouTube 기능 켜기
아래 버튼을 누르면 "YouTube Data API v3" 페이지가 열려요. 위쪽 프로젝트 이름이 방금 만든 것인지 확인 후, 파란색 "사용(Enable)" 버튼을 누르세요.
➜ YouTube API 켜기 페이지 열기
4
인증키 발급받기
아래 버튼을 누르면 인증키 페이지가 열려요. 위쪽 "+ 사용자 인증 정보 만들기" 클릭 → 목록에서 "API 키" 클릭. 몇 초 뒤 화면에 AIzaSy...로 시작하는 긴 문자열이 나타나면, 그 옆 복사 아이콘을 눌러 복사하세요.
➜ 인증키 발급 페이지 열기
5
여기에 붙여넣기
복사한 키를 아래 입력칸에 붙여넣기(Ctrl+V)하고 "저장" 버튼을 누르면 끝!
💡 화면이 영어로 나오거나 헷갈리시면, 유튜브에서 "구글 유튜브 API 키 발급받는 방법" 영상 찾아보기를 참고하셔도 좋아요. 전부 무료이며 카드 결제가 청구되지 않습니다.
